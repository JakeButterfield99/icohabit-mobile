# iCohabit Mobile App

This is the frontend/mobile portion of my iCohabit project. This was built as a house organisation tool for households - particularly focusing on new students.

Backend/API [HERE](https://github.com/JakeButterfield99/icohabit-laravel)

## Features

- Add members to your 'household'
- Shared tasks/chores list
- Shared grocery list & meal ideas
